Every face here is served from this domain and licensed for it. Nothing is
fetched from a third party at page load.

EB Garamond — latin and cyrillic
  Google Fonts' own per-script builds, downloaded as-is and not cut further.
  SIL Open Font License 1.1 — see OFL.txt.
  Upstream: https://github.com/octaviopardo/EBGaramond12

Noto Serif TC / SC / JP / KR — subsets
Siao Switcher Han / Hangul — subsets
  Cut from the Noto CJK Serif faces by scripts/subset-font.py, down to the few
  dozen characters each page draws. The switcher pair carries only the ten
  language names in the menu; Han comes from the Simplified face because it is
  the only one holding all of them.
  SIL Open Font License 1.1 — see OFL-NotoCJK.txt.
  Upstream: https://github.com/notofonts/noto-cjk

Noto Naskh Arabic — subset
  Cut by the same script. The layout tables are kept: Arabic is drawn by
  substitution, and a subset without them renders every letter in its
  isolated form.
  SIL Open Font License 1.1 — see OFL-NotoNaskhArabic.txt.
  Upstream: https://github.com/notofonts/notofonts.github.io

characters.json is generated by scripts/build.js from i18n.js. It is the input
to the subsetting script, and it is not maintained by hand — a written-down
character list is a second copy of the site's text, and the two drift.
